1//! SDL configuration variables
2//!
3//! This file contains functions to set and get configuration hints,
4//! as well as listing each of them alphabetically.
5//!
6//! The convention for naming hints is SDL_HINT_X, where "SDL_X" is
7//! the environment variable that can be used to override the default.
8//!
9//! In general these hints are just that - they may or may not be
10//! supported or applicable on any given platform, but they provide
11//! a way for an application or user to give the library a hint as
12//! to how they would like the library to work.
13

38/// A variable controlling how 3D acceleration is used to accelerate the SDL
39/// screen surface.
40///
41/// SDL can try to accelerate the SDL screen surface by using streaming
42/// textures with a 3D rendering engine. This variable controls whether and
43/// how this is done.
44///
45/// This variable can be set to the following values:
46/// * "0": Disable 3D acceleration
47/// * "1": Enable 3D acceleration, using the default renderer.
48/// * "X": Enable 3D acceleration, using X, where X is one of the valid
49///  rendering drivers. (e.g. "direct3d", "opengl", etc.)
50///
51/// By default SDL tries to make a best guess for each platform whether
52/// to use acceleration or not.
53pub const SDL_HINT_FRAMEBUFFER_ACCELERATION: &[u8] =
54  c_str!("SDL_FRAMEBUFFER_ACCELERATION");
