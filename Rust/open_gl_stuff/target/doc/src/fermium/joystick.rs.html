1//! Module for SDL joystick event handling.
2//!
3//! The term `device_index` identifies currently plugged in joystick devices
4//! between 0 and SDL_NumJoysticks(), with the exact joystick behind a
5//! device_index changing as joysticks are plugged and unplugged.
6//!
7//! The term `instance_id` is the current instantiation of a joystick device in
8//! the system, if the joystick is removed and then re-inserted then it will get
9//! a new instance_id, instance_id's are monotonically increasing identifiers of
10//! a joystick plugged in.
11//!
12//! The term `JoystickGUID` is a stable 128-bit identifier for a joystick device
13//! that does not change over time, it identifies class of the device (a X360
14//! wired controller for example). This identifier is platform dependent.
15//!
16//! In order to use these functions, [`SDL_Init`] must have been called
17//! with the [`SDL_INIT_JOYSTICK`] flag. This causes SDL to scan the system
18//! for joysticks, and load appropriate drivers.
19//!
20//! If you would like to receive joystick updates while the application
21//! is in the background, you should set the
22//! [`SDL_HINT_JOYSTICK_ALLOW_BACKGROUND_EVENTS`] hint before calling
23//! `SDL_Init`.
24//!
25//! See Also: [`gamecontroller`](crate::gamecontroller)
26

49/// This is a unique ID for a joystick for the time it is connected to the
50/// system.
51///
52/// It is never reused for the lifetime of the application. If the joystick is
53/// disconnected and reconnected, it will get a new ID.
54///
55/// The ID value starts at 0 and increments from there.
56///
57/// The value -1 is an invalid ID.
58#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, PartialOrd, Ord, Hash)]
59#[repr(transparent)]
60pub struct SDL_JoystickID(pub i32);
